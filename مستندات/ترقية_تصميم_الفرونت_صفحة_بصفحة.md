# 🎨 دليل الترقية البصرية — AI-COS Pharmacy
## نظام تصميم موحد + اقتراحات صفحة-بصفحة (بقصاصات كود جاهزة)

> **الفلسفة:** عندك أصلاً نظام Material 3 (surface-container / primary بنفسجي #4f46e5 / emerald للحياة / rose للأمان + خط Cairo). المطلوب ليس تغيير الهوية بل **ترقيتها**: تدرجات، عمق، حركة دقيقة (micro-animations)، وحالات انتقال. القاعدة الذهبية: **أنيميشن يخدم المعنى لا يزخرف** — 150-300ms، ease-out دائماً.

---

## 0️⃣ الأساس — أضفه مرة واحدة في `globals.css` (كل الصفحات تستفيد)

```css
/* ═══ AI-COS Design Motion & Depth Kit ═══ */

/* 1. دخول العناصر من الأسفل — لكل الكروت عند التحميل */
@keyframes fade-up {
  from { opacity: 0; transform: translateY(14px); }
  to   { opacity: 1; transform: translateY(0); }
}
.animate-fade-up { animation: fade-up .45s cubic-bezier(.16,1,.3,1) both; }
.animate-fade-up-1 { animation: fade-up .45s .05s cubic-bezier(.16,1,1) both; }
.animate-fade-up-2 { animation: fade-up .45s .12s cubic-bezier(.16,1,1) both; }
.animate-fade-up-3 { animation: fade-up .45s .2s cubic-bezier(.16,1,1) both; }

/* 2. توهج حي للبطاقات الإحصائية (نبض خفيف على الحد) */
@keyframes border-glow {
  0%,100% { box-shadow: 0 0 0 0 rgba(79,70,229,.35); }
  50%     { box-shadow: 0 0 0 4px rgba(79,70,229,.08); }
}
.kpi-glow { animation: border-glow 3s ease-in-out infinite; }

/* 3. زجاجية (Glassmorphism) للهيدر والبطاقات المميزة */
.glass {
  background: rgba(255,255,255,.65);
  backdrop-filter: blur(14px) saturate(1.4);
  border: 1px solid rgba(255,255,255,.5);
}

/* 4. تدرج نصي للعناوين الرئيسية */
.text-gradient {
  background: linear-gradient(90deg, #4f46e5, #7c3aed 45%, #059669);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

/* 5. خط متدرج علوي للبطاقات (Accent Bar) */
.accent-top { position: relative; overflow: hidden; }
.accent-top::before {
  content: ""; position: absolute; inset: 0 0 auto 0; height: 3px;
  background: linear-gradient(90deg, #4f46e5, #06b6d4, #10b981);
}

/* 6. Shimmer أثناء التحميل (أجمل من pulse) */
@keyframes shimmer {
  0% { background-position: -400px 0; }
  100% { background-position: 400px 0; }
}
.skeleton {
  background: linear-gradient(90deg, #eef2ff 25%, #f8fafc 50%, #eef2ff 75%);
  background-size: 800px 100%;
  animation: shimmer 1.4s infinite linear;
  border-radius: 8px;
}

/* 7. hover رفع ناعم للبطاقات القابلة للنقر */
.card-lift { transition: transform .2s ease-out, box-shadow .2s ease-out; }
.card-lift:hover { transform: translateY(-4px); box-shadow: 0 12px 28px -8px rgba(79,70,229,.25); }

/* 8. عدّاد الأرقام ينبض عند التحديث (للـ KPIs الحية) */
@keyframes count-pop { 0% { transform: scale(1); } 50% { transform: scale(1.12); } 100% { transform: scale(1); } }
.count-pop { animation: count-pop .4s ease-out; }

/* 9. خلفية شبكة خفيفة للأقسام التقنية */
.grid-bg {
  background-image: linear-gradient(rgba(79,70,229,.05) 1px, transparent 1px),
                    linear-gradient(90deg, rgba(79,70,229,.05) 1px, transparent 1px);
  background-size: 24px 24px;
}
```

**قواعد الاستخدام:** كل بطاقة إحصائية = `animate-fade-up-N` + `card-lift` · كل عنوان صفحة = `text-gradient` · كل بطاقة KPI = `kpi-glow` · الهيدر الثابت = `glass`.

## 1️⃣ Dashboard (`/admin`)
**الوضع الحالي:** 4 بطاقات أرقام + بطاقة AI Layer + 5 بطاقات واجهات — جيدة لكنها مسطحة.
1. **الـ KPI Cards:** `kpi-glow` + `card-lift` + الأيقونة داخل دائرة بتدرج (`bg-gradient-to-br from-indigo-500 to-violet-600 text-white shadow-lg shadow-indigo-300/40`) بدل الرماد.
2. **رقم الـ KPI:** عند تغير القيمة أضف class `count-pop` لحظياً (useEffect على القيمة) — يبدو أن الرقم "نفسه يتنفس".
3. **"Active AI Agents 9/9":** اجعل النقاط الـ 9 نقاط نابضة فعلاً: كل اسم وكيل داخل شريحة صغيرة بنقطة خضراء `animate-ping` خفيفة — يعطي إحساس "نظام حي".
4. **الهيدر:** `glass` فوق خلفية متدرجة خفيفة (`bg-gradient-to-br from-slate-50 via-indigo-50/40 to-emerald-50/30`).
5. **خمس الواجهات الرئيسية:** البطاقات العشر إلى `card-lift` مع `accent-top` بلون مختلف لكل قسم (عملاء=indigo، كتالوج=cyan، طلبات=emerald، مراجعة=violet، متجر=amber).

## 2️⃣ AI Review (`/admin/ai-review`)
**الطابع المطلوب: غرفة عمليات سريرية (Clinical Ops).**
1. **الصفوف الحرجة (severity=critical):** حد يمين أحمر متوهج `border-r-4 border-r-red-500 bg-red-50/40` + أيقونة نبض قلب صغيرة animate-pulse — يخبر الصيدلي "هذا يحتاجك" قبل قراءة أي كلمة.
2. **زر Approve:** عند النجاح، الصف يختفي بأنيميشن `collapse` (height→0 + opacity، 250ms) بدل الاختفاء الفوري — إحساس "قائمة تتشاطف".
3. **عدّاد القائمة:** عند تغيره، `count-pop` على الرقم.
4. **شريط علوي متدرج** `from-emerald-600 to-teal-600` للعنوان (نفس هوية نتيجة الروشتة) — يوحّد لغة "القرار السريري".
5. **Confidence كحلقة تقدم (Ring)** بدل نص نسبة: SVG دائرة صغيرة بلون حسب النسبة — لمسة بصرية فاخرة وسهلة (div دائري conic-gradient).

## 3️⃣ Agentic AI (`/admin/agentic-ai`)
**الطابع: غرفة تحكم بوكلاء (Mission Control).**
1. **بطاقة كل وكيل:** `accent-top` بلون هوية الوكيل + `card-lift`، وحالة الوكيل كنقطة حية.
2. **أثناء تشغيل وكيل:** الزر يتحول لشريط تقدم "خيطي" (خط متحرك gradient ينزلق — نفس فكرة shimmer) + النص "يفكر…" مع 3 نقاط قفز (`animate-bounce` متدرج التأخير).
3. **نتيجة الوكيل تظهر بأنيميشن كتابة (Typewriter) للملخص التنفيذي** — تأثير سينمائي بسيط: `useEffect` يقص الحرف حرفاً كل 15ms. (هذا أجمل تأثير ممكن في مشروعك — والجمهور سيصمت له).
4. **`execution_source` كشارة:** `n8n:aicos-analytics` = شريحة سماوية ☁ مع أيقونة cloud، وlocal = شريحة رمزية 🖥 — **تعرض هندستك الهجينة بصرياً**.
5. **Model Manager:** بطاقة النموذج النشط تحصل على إطار تدرج (`p-[2px] bg-gradient-to-r from-indigo-500 to-emerald-500 rounded-xl` واللوحة داخله بيضاء) + وسم "ACTIVE".

## 4️⃣ Business Value (`/admin/business-value`)
**الطابع: تقرير مجلس إدارة تفاعلي.**
1. **بطاقة الوفر المقدر = البطاقة الملكية:** خلفية متدرجة داكنة `from-indigo-600 via-violet-600 to-emerald-500 text-white` + رقم ضخم `text-4xl font-black` + `kpi-glow` — هذه البطاقة التي ستُصور في التقرير.
2. **الفانل:** الأشرطة تتحرك من 0 إلى قيمتها عند التحميل (transition + delay متدرج لكل خطوة) + لون كل خطوة يتدرج (أخضر→تركوازي→بنفسجي) + عند hover تظهر tooltip بحجم الهبوط.
3. **الـ Scorecard:** كل مؤشر بشريط تقدم صغير ملون (أخضر < 5% اصفر < 15% أحمر حسب طبيعته).
4. **عند تحقق السلسلة (verify):** شعار درع ينبض ثم علامة صح خضراء كبيرة بأنيميشن `scale-in` — لحظة العرض الذهبية.
5. **تصدير تقرير اللجنة:** عند الضغط، الزر يتحول لspinner + toast "جارٍ التحضير" (نفس نمط الشات).

## 5️⃣ Customers / Orders / Catalog
1. **الصفوف:** hover يرفع الصف قليلاً + حد جانبي يظهر بلون حالة الطلب (Completed=emerald، Pending=amber، Cancelled=rose).
2. **الشارات (Status pills):** أيقونة صغيرة داخل الشارة + تنبض فقط لو status=pending.
3. **البحث:** عدّاد النتائج يظهر بعد البحث بـ `count-pop`؛ إدخال البحث يكبر خط الإطار `focus:ring-4 focus:ring-primary/15`.
4. **الصور المفقودة:** `MedicinePlaceholder` يظهر بتحويلة fade-in بدل القفز.

## 6️⃣ Analytics (`/admin/analytics`)
1. **الكوبيلوت التنفيذي:** خلفية القسم `grid-bg` + نص الملخص يُكتب بأنيميشن typewriter مثل نتيجة الوكلاء + شارة "Optuna Tuned".
2. **الأرقام الكبيرة (revenue/orders):** `text-gradient` + عدّاد يصعد من 0 إلى القيمة خلال 800ms (CountUp بسيط بـ requestAnimationFrame — 20 سطر).
3. **حدود البطاقات:** `accent-top` بألوان المحاور (مالي=indigo، سريري=emerald، استبقاء=violet، تشغيلي=cyan).

## 6️⃣ Audit Trail (`/admin/audit-logs`)
**الطابع: خزانة سجلات مضادة للعبث — جدية ومظلمة قليلاً.**
1. **بطاقة التحقق من السلسلة:** خلفية `from-slate-900 to-indigo-950 text-white` مع أيقونة درع؛ عند التحقق الناجح: **تموّج أخضر يمر على البطاقة** (`background: linear-gradient(90deg, transparent, rgba(16,185,129,.25), transparent)` sweep) + "✅ السلسلة سليمة — 0 روابط مكسورة" بحجم كبير.
2. **صفوف السجل:** أيقونة نوع الحدث بلون فئته (أمان=أحمر، سريري=emerald، حوكمة=indigo) + طابع زمني بخط mono صغير.
3. **زر التحقق أثناء الفحص:** النص يتحول "يفكك السلسلة…" مع حلقة تدوير.

## 7️⃣ Storefront + Profile (وجه المريض)
1. **Storefront:** البطاقات بـ `card-lift` + صور المنتج `transition-transform group-hover:scale-105`. شريط علوي `glass`.
2. **Profile:** الهيدر الحالي أزرق داكن — أضف خلفية `bg-gradient-to-br from-indigo-900 via-violet-800 to-emerald-900` + أنيميشن دخول للكروت. بطاقات الـ KPI الشخصية بـ `kpi-glow`.
3. **حالة فارغة جميلة:** "بانتظار أول طلب ⏳" — حولها لرسمة SVG صغيرة (كبسولة + قلب نابض) بدل نص فقط، مع زر "ابدأ أول طلب" يقفز للكتالوج.

## ⚖️ قواعد الحركة الثلاث (اكتبها في سلايد "هندسة التجربة")
1. كل أنيميشن بين **150–450ms** بمنحنى `cubic-bezier(.16,1,1)` — لا شيء يتجاوز 400ms.
2. الحركة تعبّر عن المعنى: أخضر=اكتمال، نبض=حياة/انتظار، خروج=إنهاء. لا حركة بلا معنى.
3. احترام `prefers-reduced-motion` — أضف في globals.css:
```css
@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
```
