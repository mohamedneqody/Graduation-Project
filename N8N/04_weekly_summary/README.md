# سير العمل 04: الملخص التنفيذي الأسبوعي (weekly_summary)

## 📌 نبذة عامة
مسار الذكاء التنفيذي للإدارة العليا (Executive Intelligence Digest). يقوم بتلخيص مؤشرات الأداء الحيوية (KPIs)، والعائد على الاستثمار من الحرس السريري (CDSS ROI)، ومعدلات الأمان في تقرير موحد يُرسل للإدارة.

## 🎯 الأهداف التشغيلية
1. **الجدولة الدورية:** صباح كل يوم اثنين في الساعة 8 صباحاً عبر `Schedule Trigger`.
2. **الاستدعاء الفوري:** من زر "weekly_summary" بلوحة الإدارة.
3. **توليد مؤشرات الأداء:** استدعاء نقطة النهاية `/api/v1/business-value/roi`.
4. **توصيل التقرير التنفيذي:** إرسال رسالة تيليجرام مهنية منسقة بصيغة HTML للإدارة ومجلس الإدارة.

## 🚀 كيفية الاستيراد إلى n8n
1. استورد ملف `workflow.json` في n8n.
2. تأكد من أن الـ Webhook Path مضبوط على `weekly_summary`.
3. اضغط **Save** واجعل المسار **Active**.
