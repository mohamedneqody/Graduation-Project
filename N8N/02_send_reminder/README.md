# سير العمل 02: إرسال التذكيرات للمرضى (send_reminder)

## 📌 نبذة عامة
مسار التنفيذ الميداني لرسائل التذكير. يسحب الحالات المعلقة من جدول الحوكمة، ويفصل بين الحالات الآمنة المصرح لها بالإرسال الآلي (`auto_send`) والحالات التي تتطلب موافقة الصيدلاني البشري (`human_review`).

## 🎯 الأهداف التشغيلية
1. **جلب التذكيرات الجاهزة:** استدعاء `/internal/governance/pending`.
2. **التوجيه الذكي (Decision Routing):**
   - **مسار الإرسال الآلي (True):** يرسل التذكير فوراً للمريض على تيليجرام ثم يحدّث الحالة في قاعدة البيانات إلى `sent`.
   - **مسار الحوكمة البشرية (False):** يرسل إشعاراً عاجلاً للصيدلي بوجود حالة تحتاج مراجعة قبل إرسال الدواء.
3. **الحماية من التكرار:** يتم تحديث الـ DB فوراً حتى لا تصل الرسالة مرتين للمريض.

## 🚀 كيفية الاستيراد إلى n8n
1. في n8n، أنشئ Workflow جديد أو استورد ملف `workflow.json`.
2. تأكد من ضبط الـ Webhook Path على: `send_reminder`.
3. اضغط **Save** وتأكد من حالة **Active**.
