# سير العمل 03: إرسال عروض الخصم والكوبونات (send_discount_offer)

## 📌 نبذة عامة
مسار التسويق الذكي الموجه بالذكاء الاصطناعي لمكافحة تسرب العملاء (Customer Churn Prevention). يستهدف العملاء ذوي احتمالية الانسحاب المرتفعة عبر توليد كوبون خصم شخصي وصياغة رسالة تسويقية طبية محفزة.

## 🎯 الأهداف التشغيلية
1. **التكامل مع وكيل التسويق (AI Marketing Agent):** يرسل بيانات العميل ونسبة الخصم المقترحة إلى `/api/v1/agents/marketing/generate-campaign`.
2. **توليد الكوبون الآلي:** إصدار كود ترويجي فريد مخصص للعميل.
3. **التسليم السريع:** إرسال العرض الترويجي عبر قناة تيليجرام.

## 🚀 كيفية الاستيراد إلى n8n
1. استورد ملف `workflow.json` في n8n.
2. تأكد من أن الـ Webhook Path مضبوط على `send_discount_offer`.
3. اضغط **Save** واجعل المسار **Active**.
