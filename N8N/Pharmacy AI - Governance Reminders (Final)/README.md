### 📌 ملخص سريع للمنظومة:
1. **البيانات الأولية:** فواتير وسجلات مشتريات الأدوية في PostgreSQL / Supabase.
2. **الذكاء التحليلي وتعلم الآلة:** حساب دورات انتهاء الدواء + نموذج XGBoost لتوقع احتمالية فقدان المريض (`churn_probability`).
3. **الحوكمة السريرية (Human-in-the-Loop):** تحويل الحالات ذات الخطر المرتفع (`> 70%`) للمراجعة البشرية، واعتماد الحالات الآمنة تلقائياً.
4. **الذكاء الاصطناعي التوليدي:** توليد رسائل تذكير شخصية وكوبونات خصم 15% للمرضى المعرضين للانقطاع.
5. **الأتمتة متعددة القنوات عبر n8n:** إرسال فوري عبر Telegram + Email وتحديث قاعدة البيانات لحظياً.
