## 🧑‍⚕️ أولًا: للمريض (واجهة المتجر — localhost:3000)

### التسوق والشراء
1. تصفح **الأدوية (114+)** أو ابحث بالاسم/التصنيف
2. افتح أي دواء → سترى: المادة الفعالة · الجرعة · التحذيرات · **السعر الرسمي من القاعدة**
3. أضف للسلة → أتمم الطلب → الكوبون إن وُجد يُطبق تلقائيًا

### 💬 المحادثة الذكية (3 طرق)
| الطريقة | كيف |
|---|---|
| ✍️ كتابة | اكتب سؤالك (بالعربي العامية عادي: "سعر بنادول كام؟") |
| 🎤 صوت | دوس 🎤 واتكلم → كلامك يتحول نص → أرسل |
| 📷 روشتة | صوّر روشتة خط اليد → تُقرأ وتُطابق وتتجهز سلة |

**🔊 استماع:** تحت كل رد زر **🔊 استمع** → البوت يقرا الرد بصوت أنثى.
**⚡ الطوارئ:** أي وصف لألم صدر/ضيق تنفس (حتى بالعامية) → تنبيه إسعاف 123 فوري.

### ⚠️ حدود النظام (مهم)
البوت **إرشادي** — لا يشخص ولا يغني عن الطبيب، ولا يصرف دون روشتة لأدوية الجدول، ويرفض بأدب أي محاولة اختراق.

### 🛡️ الحوكمة (Maker/Checker) — للقرارات الحساسة (CRITICAL)
1. **Maker** يعتمد → الحالة: *بانتظار التحقق الثاني* — **لم يُنفَّذ** ✋
2. **Checker** (مستخدم مختلف) يعتمد → يُنفَّذ **مرة واحدة** ✓
3. نفس الشخص لا يستطيع تنفيذ الاثنين — والنظام يرفض محاولته ✓
4. كل خطوة موثقة في **WORM** (سجل غير قابل للتعديل) و**Outbox** بحالة حية

### 🏥 الروشتات بخط اليد
زر 📷 في الشات → صوّر الروشتة → تُقرأ وتُطابق (عتبة صارمة ≥65%)
- المتوفر → سلة بأسعار رسمية
- غير المتوفر → 🟥 كارت أحمر **بلا بدائل عشوائية**
- منخفض الثقة → مراجعة الصيدلي (HITL) قبل الصرف
