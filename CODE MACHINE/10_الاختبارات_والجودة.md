## 3. التقييم الحي (فوق الاختبارات) — منهجية مبتكرة

الاختبارات تثبت المنطق؛ **القياس الحي يثبت الواقع**. الأدوات (`probe_*.py`):

1. **probe_whatif_live.py** — طبقتان: حماية HTTP (401 لكل النقاط بلا توكن) + مسار داتا كامل على الإنتاج
2. **probe_churn_eval.py** — قياس موديل churn المنشور ضد واقع اليوم (الحقيقة المطلقة من الداتابيز)
3. **probe_churn_compare.py** — مواجهة عادلة v1 ضد v2 (عينة عشوائية مثبتة البذرة — نفس الأفراد للنموذجين)

**أمثلة ما اكتشفه القياس الحي ولم تكشفه الاختبارات:**
- إنذارات v1 الكاذبة (66/120) → قصة v2
- 4 مواضع كتابة تدقيق صامتة العطب (عمود `log_id`) → إصلاح جذري بسطر واحد
- انحياز عينة المقارنة الأول (ترتيب بمتوسط الدورة) → إصلاح ببذرة عشوائية مثبتة

> "الاختبار يثبت أن الكود يفعل ما قلنا؛ القياس الحي يثبت أن ما قلنا هو المطلوب فعلًا."

## 4. قصة جودة كاملة: من الاكتشاف إلى النشر (churn v2)

```
قياس حي → تشخيص (تسريب label + ضجيج + انحياز عينة + إشارة سكانية غائبة)
   → إعادة بناء خط التدريب (4 إصلاحات موثقة بالكود)
   → مواجهة عادلة v1 ضد v2 على نفس العينة (بذرة مثبتة)
   → فوز واضح (F1 53.2 → 79.0، إنذارات كاذبة 66 → 2)
   → نشر بتراجع لحظي (v1 محفوظ؛ الرجوع = حذف ملف)
   → 158/158 اختبار انحدار ناجح
```
