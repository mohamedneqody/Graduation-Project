# 06 — الصفحات والواجهات (Next.js 15 — App Router)

إجمالي الواجهة: **29 صفحة** + مكونات متخصصة. اللغة عربية RTL بالكامل مع داكن/فاتح.

## أ) واجهة العميل (7 صفحات)

| الصفحة | الوظيفة | نقطة القوة |
|---|---|---|
| `/` | الرئيسية: هيرو + تصفح الكتالوج حي + الأكثر طلبًا | "Powered by Live PostgreSQL Data" — بيانات حية لا ثابتة |
| `/catalog` | الكتالوج الكامل بالتصنيفات (مسكنات، مزمن-سكر...) | فلترة وتقسيم حقيقيان |
| `/checkout` | السلة + كوبونات | الكوبون يتحقق من endpoint حقيقي + إعادة توجيه دخول بـ redirect |
| `/orders` | طلبات العميل | فاتورة ETA ضريبية (Modal) |
| `/profile` | الملف الشخصي | — |
| `/about` | التعريف بالفريق | مدقق لغويًا وفقنيًا (3 تصحيحات موثقة) |
| `/contact` | الدعم | — |

**مكونات العميل:** `CartDrawer` (سلة منسدلة)، `PrescriptionModal` (رفع روشتة بالذكاء الاصطناعي)، `MedicineDetailsModal`، دردشة عائمة `FloatingChatWidget` (الصيدلي الذكي بحماية PII وبوابة التداخلات)، خلفية Vanta تفاعلية.

| الوحدة | المسار | الوظيفة |
|---|---|---|

## ج) طبقة الاتصال `lib/api.ts`

`fetchApi`: JWT تلقائي + إعادة محاولة + كشف 431 + تحديث توكن صامت + سقوط مباشر للباك-إند لو البروكسي فشل — تجربة مستقرة تحت أي ظرف شبكة.
