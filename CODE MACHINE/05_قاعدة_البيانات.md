# 05 — قاعدة البيانات (PostgreSQL / Supabase)

بيئتان: **الإنتاج** (Supabase عبر `.env`) و**الاختبار** (Docker منفذ 55432 — `docker-compose.test.yml`).
كل جدول أعمال عليه **RLS** بعزل `tenant_id`.

## جداول الهوية والتجارة

| الجدول | الوظيفة | ملاحظات |
|---|---|---|
| `tenants` | المستأجرون (كل صيدلية/متجر) | أصل كل العزل |
| `customers` | العملاء: `role` (customer/admin/pharmacist) + `age_group` | 3 أدوار فقط؛ الدور يحدد كل الصلاحيات |
| `drugs` | الكتالوج: `base_price`, `active_ingredient`, `is_chronic`, `is_verified`, `default_cycle_days` | مصدر سعر What-If؛ ~116 دواء حي |
| `inventory_items` | `stock_level`, `reorder_point`, `tenant_price` | مصدر المخزون وسيناريو الراكد |
| `orders` + `order_items` | الطلبات (status: completed…) + الكميات والأسعار | مصدر كل التحليلات والتنبؤات |
| `customer_cycles` | دورة شراء كل عميل×دواء (`avg_cycle_days`) | أصل تدريب نماذج التنبؤ |

## جداول المشتريات والمالية

| الجدول | الوظيفة |
|---|---|
| `purchase_orders` + `purchase_order_items` | فواتير التوريد P2P — **`unit_cost` = مصدر التكلفة الحقيقية** للمحاكي والتسعير |
| `trial_balance` + قيود اليومية | الأستاذ العام (AIS) — مصدر الرؤية المالية |
| `working_capital` / forensics | رأس المال وكشف التلاعب المحاسبي |

## جداول الذكاء والحوكمة

| الجدول | الوظيفة | ملاحظة صدق |
|---|---|---|
| `coupons` | دورة حياة الكوبون كاملة: إنشاء ← صلاحية ← استرداد ذري ← انتهاء | `campaign_type='whatif_lab'` يميز ما نشره المحاكي |
| `simulation_runs` | سجل محاكاة What-If + **بروفة مصدر التكلفة** (`cost_source`) + التعادل المتوقع | أُنشئ 20-09-2026 |
| `pending_reminders` | التذكيرات المعلقة + `churn_probability` + `cycle_confidence` | Pull-based لـ n8n |
| `audit_logs` | سجل التدقيق الرسمي | `log_id` الآن default `gen_random_uuid()` (إصلاح 4 مواضع صامتة) |
| `automation_runs` | تشغيلات الأتمتة + مقاييس callback | حلقة القياس مع n8n |
| `drug_interactions` | التداخلات الدوائية (severity: low/medium/high) | بوابة CDSS الصلبة |
| `drug_affinities` | علاقات التكامل (توصيات متقاطعة) | مصدر cross-sell الحقيقي |
| `ocr_corrections` | تصحيحات HITL للروشتات | حلقة التعلم البشري |
| `outbox` | رسائل مضمونة التسليم | Offline-first |
| `ab_tests` | اختبارات A/B | تقيس أثر الميزات فعليًا |

## العلاقات الذهبية (احفظ 3)

```
orders → customers    (من يشتري)
order_items → drugs   (يشتري إيه)
purchase_order_items.unit_cost → drugs  (التكلفة الحقيقية — بلاها مفيش هامش صادق)
```

## لماذا PostgreSQL/Supabase تحديدًا؟

1. **RLS جاهز** — عزل المستأجرين على مستوى قاعدة البيانات نفسها (وليس الكود فقط)
2. **نافذة LAG** و `DISTINCT ON` — حسابات الفجوات الزمنية للتدريب داخل SQL
3. **أقفال صفية FOR UPDATE** — الاسترداد الذري للكوبونات
4. Supabase = مصادقة GoTrue جاهزة + Postgres حقيقي كامل الصلاحيات (نافذة، CTE، Triggers)
