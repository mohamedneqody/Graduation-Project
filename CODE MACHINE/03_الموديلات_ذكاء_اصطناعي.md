# 03 — الموديلات: كل موديل يعمل إيه بالظبط ⭐ (أهم ملف)

المشروع فيه **عائلتان من النماذج** مدربتان فعليًا (ملفات `.joblib` حقيقية في `backend/models/`) + محرك LLM طبقي + نظام OCR. هذا الملف يشرح كل واحد: مدخلاته، مخرجاته، دقته، وأين يعمل.

---

## ① موديل توقع مغادرة العملاء (Churn) — v2 المنشور حاليًا

| البند | التفصيل |
|---|---|
| **الملف** | `models/churn_tuned_v2.joblib` (v1 محفوظة للرجوع الفوري) |
| **الخوارزمية** | XGBoost (تصنيف ثنائي) مضبوط بـ **Optuna** (بحث بايزي 30 تجربة) + توازن **SMOTE** + ضبط **عتبة القرار** (0.43) |
| **السؤال الذي يجيبه** | "ما احتمال أن هذا العميل انقطع عن شراء هذا الدواء؟" |
| **المدخلات (12 خاصية)** | أيام الصمت، نسبة الصمت للدورة الافتراضية للدواء، **نسبة الصمت للفجوة السكانية للدواء** (الجديدة — مفتاح الدقة)، عدد المشتريات، ثبات الدورة، تكرار شراء العميل شهريًا، عمر العميل، فئة العمر، فئة الدواء، سعر الدواء، مزمن/لا |
| **المخرجات** | `churn_probability` (0→1) + تصنيف خطر (low/medium/high) + قرار + **أهم 3 عوامل SHAP** |
| **التعريف** | منقطع = صمته تجاوز 1.5×دورته الشخصية (نفس قياس الإنتاج حرفيًا) |
| **الدقة الحية** | دقة إنذار **94.1%**، استرجاع 68.1%، F1 **79.0%** — مقابل v1: 38.3%/87.2%/53.2% |
| **أين يعمل** | `/prediction/churn` + التذكيرات السريرية + صفحة مراجعة الذكاء + وكيل التسعير |
| **ما لا يفعله** | لا يقرر مالًا ولا يتنبأ بتكلفة استبقاء — الاحتمال فقط؛ المال محرك قطعي منفصل |

**قصة تحسينه (قصة دفاع ذهبية):** قيست v1 حيًا → 66 إنذارًا كاذبًا من 120 → تشخيص منهجي (تسريب، ضجيج مصطنع، انحياز عينة زمني، غياب الإشارة السكانية) → إعادة بناء خط التدريب → إنذارات كاذبة = 2. **الرجوع لحظي بحذف ملف واحد.**

## ② موديل توقع دورة إعادة الشراء (Regression)

| البند | التفصيل |
|---|---|
| **الملف** | `models/regression_tuned.joblib` |
| **الخوارزمية** | XGBoost Regressor مضبوط بـ Optuna (CV خماسي بمعيار MAE) |
| **السؤال** | "بعد كم يوم سيشتري هذا العميل هذا الدواء مرة أخرى؟" |
| **المدخلات (10)** | متوسط دورته السابقة، أيام الصمت، عدد المشتريات، ثبات الدورة، الفئة العمرية، فئة الدواء، الدورة الافتراضية، السعر، + |
| **المخرجات** | `predicted_days` + **فاصل ثقة غاوسي 95%** (± 1.96×σ=2.1 يوم) + تاريخ الشراء المتوقع + SHAP |
| **الدقة** | MAE = **3.27 يوم** (خطأ متوسط 3 أيام في تقدير دورة قد تكون 60 يومًا) |
| **ثقة Cold-start** | عملاء بلا تاريخ كافٍ = 0.40 معلنة بصراحة ويُستخدم دور الدواء الافتراضي |
| **صيغة الثقة** | `1 − MAE/متوسط الدورة` موسومة بأنها "ثقة تقريبية طبية" وليست احتمالية إحصائية — صدق منهجي في التسمية نفسها |
| **أين يعمل** | `/prediction/cycle` + `/combined` (يستهلكها n8n للتذكير المجدول) |

## ③ مجموعة ملفات النماذج (12 ملف .joblib) — لماذا كل هذه؟

لكل مهمة (churn/regression) **5 متسابقين دُرّبوا وقيسوا**:

| الملف | الخوارزمية | الغرض |
|---|---|---|
| `*_baseline.joblib` | Logistic/Linear | خط أساس للقياس (لو النماذج المعقدة لم تتفوق عليه = علامة خطر) |
| `*_rf.joblib` | Random Forest | متانة ضد الضوضاء |
| `*_svm.joblib` | SVM (مع CalibratedClassifierCV) | حدود قرار مختلفة |
| `*_xgboost.joblib` | XGBoost | الأفضل عادة على جداول |
| `*_ensemble.joblib` | Soft Voting (الكل معًا) | تجميع |
| `*_tuned.joblib` | الفائز بعد Optuna + SMOTE + ضبط عتبة | **المنشور في الإنتاج** |

> **نقطة دفاع:** منهجية "خط أساس + متسابقون + ضبط + نشر" هي دورة حياة MLOps كاملة مشغلة فعليًا على 401→1858 لقطة تدريب.

## ④ محرك اللغة الطبقي (LLM Engine)

| البند | التفصيل |
|---|---|
| **الملف** | `ai/llm_engine.py` |
| **الطبقات** | ① سحابة → ② حافة محلية (gemma) → ③ Gemini Flash → ④ نص احتياطي جاهز |

## ⑥ SHAP — قابلية التفسير (ليست ميزة تجميلية)

كل تنبؤ من churn/دورة يعيد أهم 3 عوامل أثّرت فيه بقيمة رقمية — مطلوب امتثاليًا (قابل للتفسير) ومطلوب عمليًا (الصيدلي يفهم "ليز؟").

## جدول ملخص — مين بيتنبأ بإيه بالظبط؟

| السؤال | من يجيبه | بأداة إيه |
|---|---|---|
| العميل هيقطع؟ | موديل churn v2 | XGBoost → احتمال + SHAP |
| هيشتري امتى؟ | موديل الدورة | XGBoost Regressor → أيام ± فاصل 95% |
| الخصم ده خسران؟ | محرك What-If القطعي | معادلات هامش/تعادل — **بلا ML** |
| أعمل خصم كام للاستبقاء؟ | محرك التسعير القطعي | اقتصاديات هامش + رفض الخسارة |
| إيه مكتوب في الروشتة؟ | Florence-Large | OCR + بوابة ثقة CDSS |
| إزاي أصيغ الرسالة؟ | LLM طبقي | صياغة فقط، بلا PII |
