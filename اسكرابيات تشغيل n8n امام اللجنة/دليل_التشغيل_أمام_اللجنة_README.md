# دليل تشغيل وكلاء الأتمتة (`n8n`) والمنظومة أمام لجنة المناقشة

يجمع هذا المجلد جميع السكربتات الحديثة والقديمة الخاصة بتشغيل واختبار وإثبات منظومة **AI-COS (`صيدلية كيورا الذكية` + `القطاعات المتعددة مثل معرض السيارات`)** أمام لجنة المناقشة بنقرة مزدوجة (`Double-Click`).

---

## 1. ملفات التشغيل السريع بنقرة واحدة (مرتبة حسب سيناريو العرض أمام اللجنة)

| رقم الملف | اسم الملف | الوظيفة أمام اللجنة |
| :---: | :--- | :--- |
| **1** | `1_تشغيل_جميع_السيرفرات_ومحرك_n8n.bat` | يشغّل حاويات `n8n` + الباك إند (`:8000`) + الفرونت إند (`:3001`) + الرؤية الحاسوبية (`:9202`) + الصوت (`:9203`). |
| **2** | `2_فحص_جاهزية_الـ17_وكيل_verify_n8n.bat` | يفحص الـ 17 مسار عمل والـ 15 Webhook ويعرض تقرير `PASS (17/17 workflows verified, 15/15 webhooks live)` بالأخضر. |
| **3** | `3_تشغيل_الـ17_وكيل_وارسال_بطاقات_الصيدلية_تليجرام.bat` | يشغّل جميع الـ 17 مسار عمل والربط الهجين (`Hybrid Execution`) ويرسل بطاقات الصيدلية الحية إلى تليجرام. |
| **4** | `4_اثبات_تشغيل_الوكلاء_على_معرض_السيارات_تليجرام.bat` | **الإثبات القاطع لتعدد القطاعات (`Multi-Vertical Proof`):** يشغّل نفس الـ 5 وكلاء على **معرض AI-COS للسيارات الحديثة** (`car_showroom`) ويرسل 5 بطاقات حية لمعرض السيارات (`م. ياسر علام`) إلى تليجرام. |
| **5** | `5_تشغيل_الـ5_وكلاء_الاذكياء_للصيدلية_سارة_عبدالله.bat` | يشغّل الوكلاء الخمسة الأذكياء على سجل المريضة **سارة عبد الله** (`30 طلباً`، `4 تداخلات دوائية`، ومحاكاة ربحية الخصم). |
| **6** | `6_سيناريوهات_المناقشة_الشاملة_defense_demo.bat` | يشغّل سيناريوهات المناقشة الشاملة للباك إند (`defense_scenarios_demo.py`). |
| **7** | `7_ايقاف_جميع_السيرفرات.bat` | يوقف جميع السيرفرات المحلية بأمان. |

---

## 2. السكربتات البرمجية الحديثة والقديمة المضمنة في المجلد

- **`run_all_n8n_agents.py`**: السكربت الشامل لتشغيل واختبار الـ 17 مسار عمل وعقد التنفيذ الهجين (`Hybrid Agent Contract`).
- **`prove_multi_vertical_n8n_agents.py`**: سكربت إثبات تعدد القطاعات (`Multi-Tenant + Multi-Vertical`) على معرض السيارات.
- **`run_5_pharmacy_agents_sara.py`**: سكربت تشغيل الوكلاء الخمسة الأذكياء (الإكلينيكي، المالي، الاستبقاء، الشكاوى، التحليلات الصباحية) للمريضة سارة عبد الله.
- **`verify-n8n-workflows.ps1`**: سكربت التدقيق الآلي لقاعدة بيانات `n8n` وحالة النشر والأمن (`403 Auth-Gate`) وحراس فحص السيرفر.
- **`start-local.ps1` & `start-aicos.ps1`**: سكربتات تشغيل المنظومة المحلية وفحص الجاهزية.
- **`run_servers.bat`, `stop_servers.bat`, `start_backend.bat`, `start_frontend.bat`, `start_ocr.bat`, `start_voicetut.bat`, `start_worker.bat`**: سكربتات التشغيل الفردية والجماعية للخوادم.
- **`defense_scenarios_demo.py`**: سكربت سيناريوهات العرض أمام اللجنة.
- **`verify_n8n_safety_patch.mjs`, `verify_n8n_operational_notifications.mjs`, `verify_n8n_reminder_patch.mjs`, `verify_coupon_templates.mjs`**: سكربتات التحقق السابقة لمسارات `n8n`.
- **`query_n8n.py`, `query_n8n_webhooks.py`, `port_8001_bridge.py`, `n8n_pharmacy_workflow_final.json`, `n8n_workflow_with_ai.json`**: السكربتات والقوالب المرجعية السابقة.
